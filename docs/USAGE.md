# GlassBogo 使用指南

## 第一次整理

1. 双击桌面 GlassBogo，屏幕下方出现分类栏。首次启动可勾选希望收录的桌面入口；也可以稍后从“＋”重新打开候选列表。
2. 点击“＋ 分类”，创建办公、开发、学习等自己需要的分类。
3. 把桌面或资源管理器中的快捷方式、应用、文档或文件夹拖到分类方块。目标留在原处，GlassBogo 只保存入口。
4. 悬浮约 120 毫秒展开分类，或单击立即展开。单击应用打开；文件夹交给资源管理器打开。
5. 已有入口可以拖到其他分类。同一入口只有一个归属；重复添加会在全部入口中定位已有项。

分类方块最多显示四个预览图标。分类过多时底部栏可横向滚动；展开面板每页最多十二个入口，滚轮和底部箭头均可翻页。分类方块可拖动排序；“待整理”是保留的系统分类。

## 键盘和批量整理

单击分类后，可以用方向键移动焦点、Enter 打开、Esc 收起，PageUp / PageDown 翻页。拖动或打开右键菜单时，面板不会因鼠标离开而立即收起。

底部搜索按钮打开工作台。“全部入口”支持按名称或目标搜索、按分类筛选，使用 Ctrl / Shift 多选后调整分类或移除引用。入口无法找到目标时会显示失效状态，可选中后“重新定位”。

移除入口只删除 GlassBogo 内的记录。移除分类会将其中入口移回“待整理”。请直接在资源管理器中处理实际文件；本程序没有复制、移动、改名或删除原文件的功能。

## 清爽桌面

设置中的“隐藏 Windows 桌面图标”默认关闭。开启时保存原状态，正常退出会恢复。这里只影响图标显示，不移动桌面内容。新桌面项目会计入底部“＋”提示，需要手动选择是否收录。

设置支持浅色、深色和跟随系统，选择显示器，鼠标离开后收起底栏，以及开机启动。默认使用低内存控件绘制；切换硬件加速需重启。Windows 的减少动画和高对比度设置会被尊重。

关闭工作台或日历不等于退出。右下角托盘菜单的“退出”会结束程序并恢复桌面；再次双击桌面快捷方式会打开现有实例的工作台。

## 日历与任务

底部日历按钮打开日历，也可从工作台打开。月历展示每天的任务数量；每周课表有四个时段。选择日期查看任务，双击任务编辑；拖动任务到日期或时段可改期。无指定时间、未完成的同日任务可以拖动排序。

任务支持日期、可选时间、完成状态、优先级、分类颜色和备注。搜索跨日期匹配标题、备注和分类，可进一步筛选未完成、已完成、逾期和重要任务。今日任务也出现在工作台中。

“中文速记”支持“明天18点交报告”“下午三点半开会”“下周一第二节高数”等表达。先识别，再核对结果并保存；默认 Ctrl+Alt+N 也能打开速记，快捷键冲突时可在设置中调整。

“固定 / 取消置顶”控制独立日历小窗。首版离线保存，不包含云同步、订阅日历或重复任务。

## 迁移、备份和恢复

- 设置可导入旧 GlassDesk 的 Data 文件夹，或旧日历的 calendar.json。导入仅读取源文件。重复分类归属保留第一个，结束后显示迁移统计。
- “导出日历”生成任务与分类的 JSON；设置中的“导出全部数据”包含入口、分类、任务和设置。
- 数据保存在 `%LOCALAPPDATA%\GlassBogo`。每天首次修改前自动备份，保留最近七份；导入、恢复前另存恢复点。
- “从备份恢复”会替换当前数据并先保存恢复副本。数据库打不开时，启动错误窗口支持选择备份恢复，原数据库先归档。
- 异常退出后的桌面显示恢复由再次启动自动尝试；也可直接运行下方命令。

```powershell
& "$env:LOCALAPPDATA\Programs\GlassBogo\GlassBogo.exe" --restore-desktop
```

更新始终使用同一个程序目录和桌面快捷方式。退出 GlassBogo 后运行仓库的 `scripts/build.ps1` 与 `scripts/install.ps1`，用户数据不在程序目录中，不会被安装替换。

## 本地插件

插件页选择含 plugin.json 的本地插件目录安装，查看来源和能力后启用。可在工作台查看卡片，也可使用插件页面、命令和入口菜单。停用或离开相关页面会结束会话；卸载仅移除插件包。

构建生成的 `artifacts/sample-plugin` 是可运行的“专注小记”示例。插件由独立进程运行，不依赖 Electron。只安装可信来源的本地程序；进程隔离用于稳定性。接入方法见 [插件 SDK](PLUGINS.md)。
