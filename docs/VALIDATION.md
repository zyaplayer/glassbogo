# GlassBogo 0.1.0 验收记录

测试日期：2026-10-28。此记录区分自动测试、隔离桌面实测与尚需真实设备确认的项目，不把编译成功视为全部体验验收。

## 环境与构建

- Windows 11 x64，系统版本 10.0.26100。
- Intel Core i7-14650HX，24 个逻辑处理器，约 32 GB 内存。
- .NET 10，Release、自包含 win-x64，主程序启用 ReadyToRun。
- 最终安装版 `GlassBogo.dll` SHA-256：`29A66A0DD13E1433749530F564C306D91CF90E6BB885615BCDAC8A31F1F7CC98`。
- 默认低内存控件绘制，DWM 合成系统背景；硬件加速为可选设置。

所有界面测试在 CreateDesktop 创建的独立桌面执行，不调用 SwitchDesktop，不在用户工作桌面反复启动窗口。数据为生成的 500 个入口与 10,000 个任务；入口用不同启动参数引用同一测试应用，因此此轮不代表 500 种不同 Shell 图标的冷加载成本。

## 性能结果

单位 MB 在下表中为 MiB（1,048,576 字节）。私有内存和工作集分别记录，不混用。CPU 百分比使用进程 CPU 时间增量除以墙钟时间及逻辑处理器数量。

最终安装版交替长测结果在本次测试结束后填入。

### 前期对照

相同规模的前期低内存候选构建进行了 30 分钟分类连续切换，共 8,387 次：两分钟待机私有内存 102.0 MiB、工作集 174.6 MiB、平均整机 CPU 0.0016%；切换期间采样私有内存最高 120.5 MiB、结束 117.0 MiB，句柄 857 → 829。缓存命中分类布局 P95 为 6.26 ms。这是分类长测，不是最终安装版的日历交替长测。

硬件加速对照构建同样运行 30 分钟，待机私有内存约 188.5 MiB，超过 150 MiB 目标，因此没有作为默认模式。待机低内存候选的单次进程 GPU 计数器采样为 0%，专用/共享显存计数为 0；该采样发生在隔离桌面，排除了系统 DWM，不代表真实可见桌面始终零 GPU。

## 测量边界与待实机确认

- 分类耗时由 ShowCategory 到 UpdateLayout 返回计时，不含 120 ms 悬停等待，也不是鼠标到屏幕呈现的端到端延迟。真实 60 Hz 下的掉帧与屏幕呈现延迟尚未使用 ETW/PresentMon 测量。
- WPF 快照检查内容与布局，不包含 DWM 的实际桌面背景；真实液态玻璃观感仍需在用户桌面体验。
- 自动测试不覆盖真实鼠标穿越间隙、OLE 跨进程拖动和所有右键菜单时序。已实现延时、安全间隙、拖动/菜单保持与焦点处理，仍需实际手感验收。
- 多显示器选择、DPI、拔插、全屏收起、休眠恢复均有代码处理；目前未逐一在物理多屏和实际全屏应用上验收。
- 待机测试时插件页面关闭、插件进程退出。启用不同第三方插件后的总内存取决于该插件，需要单独测量；不将示例结果推广到任意插件。
- 自包含程序尚未代码签名。首版通过本地构建和固定安装目录更新，没有在线更新服务。
